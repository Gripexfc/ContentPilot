# 随波逐流 · Creator SaaS

## Direction

The product is a creator-facing SaaS: a calm studio where an idea becomes a shareable piece of content. The interface should invite the next creative action before it exposes operational detail.

## World

- **Material:** an airy studio canvas, quiet product navigation, large writing surfaces, and compact work-in-progress signals.
- **Palette:** canvas `#f7f8fb`, surface `#ffffff`, indigo brand `#6157d9`, coral action `#ef795e`, green success `#20a57f`.
- **Type:** one system sans family with generous readable Chinese copy. Monospace is reserved for small, factual product labels.
- **Shape:** 10–24px control/panel radii, thin cool borders, soft depth. No management-console grids, glass panels, gradient text, or decorative card nesting.
- **Iconography:** consistent line icons; the brand mark is a two-track signal path.

## Composition

The dashboard leads with a creation invitation, then a quiet line of project signals and a content stream. The workflow page leads with the brief, keeps the six-stage rail beside the form on desktop, and stacks it below on narrow screens. Navigation is a light product frame and collapses to icon-only navigation without removing settings access.

## Interaction grammar

Use 160–220ms state transitions. Hover gently lifts an actionable surface; focus uses a visible indigo ring. Indigo means “continue creating”, coral means an important action, green means complete/connected, red means blocked. Motion communicates state, never page-load choreography. Interactive list rows expose keyboard focus and Enter/Space behavior.

## Non-negotiables

Visual changes must not alter routes, API payloads, polling, local storage, session lifecycle, or platform publication boundaries. Empty, loading and error states remain explicit and readable.
